# RAG 系统介绍

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合信息检索和文本生成的人工智能技术。它通过从知识库中检索相关信息，并将其作为上下文提供给大语言模型（LLM），从而生成更准确、更可靠的回答。

## RAG 的核心组件

1. **文档加载**：从各种格式的文档（PDF、Markdown、TXT等）中提取文本内容。
2. **文本分割**：将长文档分割成适当大小的文本块，便于检索和处理。
3. **向量嵌入**：使用嵌入模型将文本转换为向量表示，捕捉语义信息。
4. **向量存储**：将向量存储在专门的向量数据库中，支持高效相似度搜索。
5. **检索**：根据用户问题从向量库中检索最相关的文档片段。
6. **生成**：将检索到的上下文和用户问题一起提交给 LLM，生成最终回答。

## RAG 的优势

- **减少幻觉**：通过提供事实上下文，显著减少 LLM 的幻觉问题。
- **知识更新**：只需更新知识库即可让系统获取新知识，无需重新训练模型。
- **可追溯**：回答可以追溯到具体的来源文档，提高可信度。
- **成本效益**：相比微调模型，RAG 的实现和维护成本更低。

## LangChain 框架

LangChain 是一个用于构建 LLM 应用程序的框架，提供了丰富的工具和抽象来简化 RAG 系统的开发。它支持多种文档加载器、文本分割器、向量存储和 LLM 集成。
